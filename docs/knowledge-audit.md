## 核验结果与取舍

1. **人数**：官方新手指引明确是6名棋手、初始60生命。社区 `wanxiang-qipu` README 中的8人说法不采纳。
2. **经济**：官方说明每回合固定获得能量、未用可结转、出售普通英雄返还1能量、基础英雄购买消耗3能量。不能从“没有写利息”推导“任何特殊天赋都不可能产生利息”；知识库只指出未证实通用存款利息规则。
3. **升级**：收益、人口和概率变化整理为C04，当前价格应看升级按钮，单独整理为E04。对“要不要升级”的建议同时检索两条，不能仅介绍收益就建议花能量。
4. **竞拍**：最高价获得；同价先出者获得；未成功不消耗竞价能量；分红比例随血量降低而提高。未收录精确分红公式及具体竞拍回合数，因为本次原文不足以支持这些细节。
5. **英雄**：上阵、同名合成、初始1级及上限999级有原文支持；未套用其他自走棋的三张升星或固定羁绊奖励。
6. **棋手与英雄别名**：只维护少量上下文内别名，例如李白→白歌；没有将香香自动映射成英雄卡孙尚香，避免棋手与英雄身份混淆。
7. **排除内容**：未核验的觉醒概率、实时胜率、最新体验服强度、完整装备表、用户战绩、首发之后全部更新差异。检索不足时承认未知。

H04、E01、E04中的“不应推断”句是本工程的证据边界说明，不是声称官网存在这些原话；L类条目是官方入门推荐，不能作为必胜或强度论证。

## 可重复核查

`scripts/verify_sources.py` 重新读取两个公开页面，去除脚本、样式及HTML注释，检查11项关键事实是否仍存在，保存网页 SHA-256 与检查时间至 `data/source_audit.json`。本次11项通过。

该检查不能证明30条知识全部正确；它用于提示页面变化。HTML哈希可能因为无关页面内容变化而改变。脚本不会自动修改知识库，也不保存整页全文。

更新时先确认正式服/体验服及公告生效时间，修改相关知识、版本范围和采集记录，再为变化补充评测案例，运行回归与真实模型评测。若来源冲突且无法消解，暂不收录相互矛盾的结论；当前仅有单一模式快照，并无完整的多版本自动冲突消解能力。
